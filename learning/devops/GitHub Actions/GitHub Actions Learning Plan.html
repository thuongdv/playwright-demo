Morning Session: Core Concepts

Key Terminology (Hover to learn):

  • Workflow
    The automated process you define in a YAML file.
  • Event
    The trigger that starts a workflow (e.g., a `push` to a branch).
  • Job
    A set of steps that run on a specific runner.
  • Step
    An individual task, which can be a script or an `action`.
  • Action
    A reusable command or script.
  • Runner
    The server that runs your workflows (e.g., GitHub-hosted or self-hosted).
